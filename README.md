# manual installs

## pokemon-colorscripts
```bash
git clone https://gitlab.com/phoneybadger/pokemon-colorscripts.git
cd pokemon-colorscripts
sudo ./install.sh
```

## wleave
```bash
cd scripts
./update_wleave.sh
```

## proton ge
```bash
cd scripts
./protonge_update.sh
```
